# FORAP documentation for anonymous review

Extract this archive and open `index.html` in a browser. The documentation uses local images, CSS, and JavaScript and does not require an internet connection. No build or installation is needed.

The nine documentation pages retain the framework explanations, architecture, principles, support packages, attributes, application steps, illustrative project descriptions, and portfolio descriptions. The FORAP name and project names are retained to preserve the technical content.

The review copy removes author contacts, public-site addresses, analytics, and externally loaded interface components. Navigation uses standard HTML links. The original overview video is replaced by its caption transcript in `overview-transcript.html`. The portfolio animation and externally shared project files are not included. The illustrative example page retains their descriptions and identifies the omitted external files. This is a documentation snapshot, not the full set of project packages.

`study-materials/questionnaire.md` contains the blank questionnaire with institutional and researcher identifiers redacted and review links redirected to this copy. It contains no participant responses. The transcript is a review substitute for the video that participants saw, not evidence of a changed study procedure.

The separate `analysis-review.zip` contains the analysis application and synthetic data for trying it locally. Neither package contains Git history or participant-level study data.
