# FORAP website for anonymous review

Open `index.html` or use the website link provided with the submission. This copy preserves the original website layout, navigation, video, animations, framework content, and project-material links.

Researcher names, email addresses, original-site metadata, and analytics are omitted for anonymous review. The questionnaire and other supplementary documents are supplied separately.

For a local preview, run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.

The original CSS, JavaScript, video, captions, and project links are unchanged. External interface libraries and fonts require an internet connection.
