00:01:30.799they can be reused and adapted by other instructors across different courses and

00:01:35.280instructional contexts. FORAP is motivated by three recurring imperatives

00:01:41.119in computing project-based learning. The first is the instructor imperative.

00:01:46.799Instructors often face substantial workload when they design a new project,

00:01:51.280adopt an existing project, adapt that project to a local course context,

00:02:40.800FORAP is intended to respond to these imperatives by organizing project

00:02:44.720materials in a more coordinated and adoption-ready way. So what is FORAP?

00:02:51.280FORAP is a packaging framework for computing PjBL projects. It is a way to

00:02:56.480organize a project so that another instructor can understand it, judge its

00:03:06.239design goals, and structural components. Together, these help define what should

00:03:15.840what FORAP is not. FORAP is not a single project. It is not a full curriculum. It

00:03:22.239is not a general PjBL process framework. It is focused on computing PjBL projects

00:03:28.560and on how those projects can be packaged with coordinated support and

00:03:32.319assessment materials. The architecture of FORAP gives the framework its
